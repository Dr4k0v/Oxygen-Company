# Aether Store

Минималистичный React-магазин цифровых продуктов. Нужен Node.js 18+.

В приложении есть вход/регистрация по логину и паролю, подарочная вкладка с одной попыткой рулетки в неделю на браузер/устройство, награды Oxygen и промокоды 10% с переходом в [Discord](https://discord.gg/WbUUT4Rbm6). Для логина `Drak0v` доступен локальный журнал событий.

Важно: это Static Site без сервера. `localStorage`, cookie и fingerprint помогают от случайных повторных регистраций в одном браузере, но не являются полноценной защитой от очистки данных, VPN или другого устройства. Для реального запрета по IP и общего журнала всех посетителей нужен backend и постоянное хранилище; статическая версия специально показывает это ограничение в панели владельца.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Деплой на Render

1. Создайте Git-репозиторий, добавьте файлы проекта и отправьте его на GitHub.
2. В [Render](https://render.com) выберите **New +** -> **Static Site** и подключите GitHub-репозиторий.
3. Render прочитает `render.yaml`. Если поля вводятся вручную: Build Command `npm install && npm run build`, Publish Directory `dist`.
4. Нажмите **Create Static Site**. Правило в `render.yaml` направляет SPA-маршруты на `index.html`, поэтому обновление вложенных URL не даст 404.
